# R52:选题预筛(写作前新增过滤层)—— 回溯判定:不成立,负结果收手

日期:2026-11-20。任务书:在写作之前把注定过不了门禁的选题挡掉;阈值不许拍脑袋,先用 R50 的 18 run 历史数据回溯;**AUC 接近 0.5 就如实写负结果收手,不硬凑结论**。

## 1. 假设与依据

R50 归因(账本 R50 段 + `08_wiki/reports/r50-passrate-after-fixes.md`):54 条 critical 锚点里 59.3% 在绑定来源全文里根本找不到(模型脑补/绑错文章),40.7% 是移花接木留痕。本轮检验的假设是:**那 59.3% 是"选题本身没有可绑定一手材料"**,即选题层面就有可测的前置信号,调阈值无效就换方向改选稿。

## 2. 预筛层实现(纯新增,既有判定零改动)

- `ttxt/writing/precheck.py`:`precheck_topic(category, topic, db_path)` 只读、不调模型、不写库。
  - **取材链与写作完全同一条**:`rag.search(limit=MATERIAL_POOL_LIMIT=15)` → `workflow._rank_materials`(取样规则、排序、选材一字未动,预筛只读它的输出);
  - **锚点抽取与归一化全部复用 `verifier.py` 现有设施**:`extract_anchors`/`norm`/`_anchor_in`/`_date_in`/`is_anaphoric_org`,并沿用门禁同口径(纯中文数量词是建议项不硬计、泛指机构不硬计)——数锚点的尺子和门禁是同一把,不另写判定;
  - 独立性口径沿用取材门禁的 `_independence_key`(作者优先,缺作者退回域名);
  - **指标先于回溯声明**(防挑数):主指标 `score = cross_verified_total` = 在 **≥2 个独立来源**全文里都能定位到的一手锚点数(R50 最大失败形状是「锚点在绑定来源找不到」,跨源都找得到的锚点最难绑错);对照指标 `first_hand_total` = 所选全文文章里可定位锚点去重数;
  - **可解释**:输出分维度锚点清单(数字/日期/人物/机构)、每篇材料标题锚点在正文的定位情况、`thin_dims`(哪个维度 0 跨源印证);`explain_rejection` 给一句话拒因与被算作缺失的具体锚点示例,不是黑箱分数。
- 既有门禁、全部阈值、取材门禁、取样规则、0.34、±1 窗口、分母 61、A+B 读数、`viral.py`、`prediction.py`:**零改动**。预筛层没有任何代码路径进入既有判定。

## 3. 回溯口径

- 标签:`03_intelligence/pass_rate_probe-20261119-r50.json` 的 18 run `passed` 字段;
- 打分:在 **R50 探针当时的类目库快照** `07_tmp/r50_passrate/<cat>_snap.db` 上计算——材料池与那 18 run 当时看到的完全一致,不受快照后语料增长污染;
- 脚本:`scripts/r52_precheck_backtest.py`,读数落 `03_intelligence/r52_precheck_backtest-20261120.json`;
- 如实登记局限:6 选题 × 3 轮,预筛分数是**选题级**(同选题三轮同分),选题内 pass/fail 翻转(生成随机性)必然压低 run 级 AUC——这是预筛层天然的天花板,已经计入。

## 5. 判定(如实,不硬凑)

1. **假设被数据否定**。「选题缺可绑定一手材料」只对**双11 类**(候选 1 篇、score=0)成立——而那 3 run 在 R50 里已经被**既有取材门禁**早退拦下(全文 1<6、独立来源 1<3),预筛在这块的增量是**零**。
2. **排序方向甚至反了**:延迟退休是锚点供给最丰的选题(cross 38 / first_hand 168),三轮全挂;R50 里它的失败形状是模型把「举例:62 岁」写成「63 岁」、55/50 岁口径 unverified——**素材里有锚点不等于模型会绑定正确的锚点**。59.3% 的脑补/绑错是生成行为,不表现为选题层锚点供给不足,锚点供给量预测不了绑定正确性。
3. 按任务书红线式约定:**AUC≈0.5 ⇒ 如实写负结果并收手,不做 6 run 重测**(重测是在已证伪的信号上烧模型时间)。6 run 小样本重测**未执行**,这是本报告的终点而非缺项。
4. 下一轮方向应由数据指路而不是继续这条线:R50 机理证据指向的是**绑定纪律**(claim↔quote 一致性、一 claim 一锚点已在 R50 起效:锚点缺失命中 37→18、伪造归属 1→0)与**正确拦截**(63岁/自媒体断言被拦是门禁在干活)。剩余阻断 fact.binding 的「形状好转未消失」提示继续在写作绑定约束与引句逐字性上做,而不是在选稿上做。
